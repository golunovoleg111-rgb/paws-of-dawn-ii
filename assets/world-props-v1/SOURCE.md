# Предметы мира v1

Живописные исходники fish-source.png, doors-source.png и sources-source.png созданы для проекта встроенным генератором изображений на предыдущем этапе работы. Повторная генерация при интеграции 16 ноября 2026 не выполнялась.

`scripts/pack-world-props.cjs` выделяет прозрачные ячейки, удаляет отдельные фрагменты соседей, сохраняет общий холст двух состояний ворот, измеряет открытый проём и упаковывает WebP. Магматическая жила сохраняет исходную нижнюю тень у границы ячейки; добавляемое техническое поле ограничено доступным изображением. Исходники сохранены для воспроизводимости. Леса переиспользуются из town-v1, а не дублируются.

Материалы сторонних игр не скопированы. Источники дизайнерских принципов перечислены в docs/design-foundation.md.
