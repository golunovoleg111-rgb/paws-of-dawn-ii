# Концепт Мисти

Статус: художественный ориентир для переработки. Не готовая 3D-модель и не кадры игровой анимации.

Создан встроенным ImageGen. PNG-оригинал: misty-design-target.png; WebP для просмотра: misty-design-target.webp.

Референс идентичности и костюма: assets/characters/misty-poses.png. Референс использован только для внешности и материалов; отдельные части персонажа не вырезались и не собирались.

Задание: профессиональный лист оригинальной взрослой кошки-воительницы Мисти в трёх ракурсах, крупный портрет и образцы материалов. Чёрная матовая шерсть, зелёные глаза, лунная металлическая броня с фиолетовым плащом. Выразительная кошачья морда, анатомически корректные руки, сформованные пластины и практичные перчатки, спокойная естественная стойка с пустыми руками, одинаковые пропорции и костюм во всех видах. Тёмный нейтральный фон, живописная детальная стилизация, крупные и средние формы, без текста, пластиковых поверхностей и геометрических суставов.

Трёхмерная модель должна разрабатываться отдельно по этому художественному ориентиру; перенос деталей с листа сам по себе не создаёт корректную геометрию или анимацию.
