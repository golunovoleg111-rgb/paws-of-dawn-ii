# Мисти: цельная модель и готовые кадры

Первый персонаж нового подхода. Это **пробная стилизованная модель**, а не финальная художественная версия всего отряда.

## Что создано

- `misty.blend`: настоящая сцена Blender с непрерывной поверхностью тела, скелетом, взвешенной бронёй, мордочкой, плащом и шестью моделями оружия.
- 42 анимационных клипа: семь действий × шесть видов оружия, 696 кадров. По 24 кадра на цикл ходьбы и бега.
- Отрисовка в Eevee с постоянной ортографической камерой и прозрачным фоном. В каждом кадре уже присутствуют тело, руки, броня и оружие.
- В браузере один вызов `drawImage` на персонажа. Нет поворотов конечностей, рисования суставов, деформации полос текстуры или сборки рук.
- Единый масштаб и точка опоры во всех кадрах. Ходьба в игре выбирается по пройденному расстоянию, атака — по моменту удара.
- Отдельный просмотрщик `model-preview.html`: смена оружия и действия, разворот, замедление, остановка и просмотр отдельных кадров.
- Проверка в игре: `/?art=3d`. Новый способ включается для Мисти; Коди, Гектор, Теддик и противники пока используют предыдущую графику.

## Повторить экспорт

Нужны Node.js, Blender 4.5 LTS и Sharp. Blender устанавливается отдельно; его дистрибутив не включён в репозиторий.

```powershell
node art/blender/export-poses.mjs
& '<путь к Blender>/blender.exe' --background --python art/blender/build_misty.py
$env:SHARP_PATH='<путь к пакету sharp>'
node scripts/pack-misty.cjs
node --test tests/*.test.js
```

Один пробный статичный рендер: добавить `-- --preview` к команде Blender. Исходные отдельные кадры остаются локально в папках клипов и исключены из Git; полные PNG-атласы сохраняются рядом с уменьшенными WebP для браузера. В память загружаются максимум два атласа с оружием, остальные подгружаются по выбору.

## Проверки и границы

Упаковщик проверяет непустой альфа-канал и отсутствие обрезания каждого кадра по четырём краям. Тесты проверяют фазу шага, остановку приседания, точку опоры и единую отрисовку. Визуальный просмотр необходим: эти проверки не доказывают художественное качество или отсутствие любых пересечений объёмной брони.

Следующая работа по модели: детализация шерсти и лица, более выразительные жесты, натяжение тетивы и вторичное движение ткани. В текущем варианте плащ движется вместе с корпусом; симуляция ткани ещё не добавлена. Внешний вид улучшений брони также требует отдельных вариантов модели; игровые характеристики снаряжения остаются частью общей системы игры.
